# AI Intrusion Detection System

An AI-powered Network Intrusion Detection System built using Python, FastAPI, Docker, Kubernetes, and Machine Learning.

## Project Structure

```
AI-Intrusion-Detection-System/
│
├── backend/
├── frontend/
├── docker/
├── kubernetes/
├── helm/
├── sample_pcaps/
├── docs/
└── README.md
```

## Goal

Build an enterprise-level IDS capable of

- Capturing packets
- Extracting network features
- Detecting attacks using Machine Learning
- Visualizing alerts on a dashboard
- Deploying using Docker and Kubernetes
